## 2 SSH 连接

> 前提：电脑网卡（连交换机的那个口）已配置静态 IP `192.168.144.100/24`。
> Windows 下执行：`New-NetIPAddress -InterfaceAlias "以太网 2" -IPAddress "192.168.144.100" -PrefixLength 24`

```bash
# 连接 Jetson
ssh thuair@192.168.144.27

# 连接树莓派
ssh thuair@192.168.144.105
```

验证两台设备在线（Windows PowerShell）：
```powershell
# ARP表直接查（比ping更快）
arp -a | findstr "192.168.144"
# 应看到 .27（Jetson）和 .105（树莓派）
```

## 3 Jetson 侧（先操作）

<a id="section-4"></a>

tail -f log/log_xx 观看日志即可

<a id="section-5"></a>

### 3.2 下面是手动启动教程

<a id="section-6"></a>

### 3.3 检查网络与串口

```bash
# 确认以太网 IP 是 192.168.144.27
ip addr show

# 确认飞控串口存在
ls /dev/ttyACM0

# 如果串口权限不足（Permission denied），执行：
sudo chmod 666 /dev/ttyACM0
```

<a id="section-7"></a>

### 3.4 启动 MQTT broker（mosquitto）

```bash
sudo systemctl start mosquitto
sudo systemctl status mosquitto   # 确认 active (running)
```

<a id="section-8"></a>

### 3.5 配置并启动 NFS 服务

```bash
# 确认 picture_nfs 目录存在
mkdir -p /home/thuair/CUADC/picture_nfs

# 确认 NFS 已配置导出（正常情况下第一次才需要做）
cat /etc/exports
# 应含有：/home/thuair/CUADC/picture_nfs 192.168.144.0/24(rw,sync,no_subtree_check,no_root_squash)
# 如果没有，执行：
echo "/home/thuair/CUADC/picture_nfs 192.168.144.0/24(rw,sync,no_subtree_check,no_root_squash)" | sudo tee -a /etc/exports
sudo exportfs -ra

# 启动 NFS 服务
sudo systemctl start nfs-kernel-server
sudo systemctl status nfs-kernel-server   # 确认 active
```

<a id="section-9"></a>

### 3.6 检查 Python 环境与 dronekit hack

```bash
python3 --version   # 应为 3.11.x（Bookworm 默认）

# 确认 navigate.py 中 dronekit hack 已启用（第 8-10 行取消注释）
head -15 /home/thuair/CUADC/navigate.py
# 应看到：
# import collections
# collections.MutableMapping = collections.abc.MutableMapping
# from dronekit import connect, VehicleMode, mavutil  <- 这一行用注释版本
```

> 如果 hack 未启用，Python 3.11 下 dronekit 会启动即崩溃。手动编辑 navigate.py 取消那两行注释。

<a id="section-10"></a>

### 3.7 选择任务配置文件并启动主程序

```bash
cd /home/thuair/CUADC

# 根据当天任务选配置文件（在 main.py 第 10 行修改）
# config_moganshan_graph.json  → 图案识别任务（mission=0）
# config_moganshan_blue.json   → 数字识别任务（mission=1）

# 启动
python3 main.py
```

> `main.py` 内已写死 `os.chdir("/home/thuair/CUADC")`，必须路径完全一致才能正常运行。

## 4 树莓派侧（Jetson 主程序启动后再操作）

<a id="section-12"></a>

### 4.1 检查硬件连接

```bash
ls /dev/video0          # 相机 USB 设备
ls /dev/i2c-3           # 流明计 I2C-3 总线（BH1750 传感器）
ls /dev/ttyAMA* /dev/ttyUSB*   # GPS 串口（用于 PPS 时间校准）
```

<a id="section-13"></a>

### 4.2 验证时间同步（关键：图像时间戳必须准）

```bash
chronyc tracking        # 查看时间同步状态
# 关键字段：
# Stratum <= 4（时间源质量）
# System time 偏移 < 10ms
# Leap status: Normal
```

> `capture_nfs.py` 启动时会自动调用 `chronyc_check.py` 阻塞等待时间校准通过，手动确认可提前知道状态。

<a id="section-14"></a>

### 4.3 启动采集程序

```bash
cd /home/thuair/CUADC
python3 capture_nfs.py
```

**`capture_nfs.py` 启动后自动完成以下步骤（无需人工干预）：**

1. 读取流明计（BH1750，I2C-3 总线）计算初始曝光值
2. 挂载 NFS（`192.168.144.27:/home/thuair/CUADC/picture_nfs` → 本地 `./picture_nfs`）
3. 等待 chronyc 时间同步通过
4. 连接 MQTT broker（`192.168.144.27:1883`）
5. 循环发送 `ready` 信号（MQTT topic: `filename`）+ 在 NFS 目录创建 `ready` 文件
6. **等待 Jetson 回发 `capture start` 命令**（MQTT topic: `command`）
7. 收到命令后开始采集：硬件 PWM（GPIO 18，10Hz）触发相机快门 → 照片以毫秒时间戳命名写入 NFS → MQTT 发送文件名通知 Jetson

## 5 Jetson 侧自检流程（观察日志判断状态）

```
[mqtt_receiver] Starting MQTT listener... connected
[mqtt_receiver] msg from raspi: ready
[mqtt_receiver] raspi send mqtt signal ready       ← MQTT 通
[mqtt_receiver] raspi send NFS file ready          ← NFS 通
[main] self check all ready, going to take off     ← 两端自检全通过
[navigate] 飞控准备就绪                             ← 飞控 GPS 已锁定，home_alt 已获取
[main] waiting for self check to be done           ← 如果一直停在这里，说明有一端未通
```

## 6 常见故障排查

| 现象 | 原因 | 解决 |
|---|---|---|
| Jetson 日志一直 `waiting for self check` | 树莓派未发 ready，或 MQTT/NFS 其中一个没通 | 检查树莓派采集程序是否在运行；检查 mosquitto 是否启动 |
| `raspi send mqtt signal ready` 出现但 `NFS file ready` 没出现 | NFS 未挂载成功 | 树莓派上 `sudo mount -t nfs 192.168.144.27:/home/thuair/CUADC/picture_nfs ./picture_nfs`；Jetson 上 `sudo exportfs -ra` |
| `Connection failed with code X`（MQTT） | broker 未运行 | Jetson 上 `sudo systemctl start mosquitto` |
| `AttributeError: module 'collections' has no attribute 'MutableMapping'` | dronekit hack 未启用 | navigate.py 第 8-10 行取消注释，见第一步第 4 条 |
| navigate 进程 `waiting for GPS` / 无法获取 home_alt | 飞控未上电或串口错误 | 确认 `/dev/ttyACM0` 存在；飞机放地面等 GPS 锁定（左上角 GPS 灯常亮） |
| 树莓派采集程序卡在 chronyc 检查 | GPS/PPS 未接好，时间源未同步 | 检查 GPS 串口接线；`chronyc sources` 查看同步源 |
| `File not found or empty` 大量出现在 Jetson 日志 | NFS 写入延迟，Jetson 在文件写完前就去读 | 正常情况下少量出现可接受；大量出现说明网络或 NFS 有问题 |

## 9 正式比赛操作顺序

```
1. Jetson 上电 → SSH → 启动 mosquitto、NFS → python3 main.py
2. 树莓派上电 → SSH → python3 capture_nfs.py
3. 飞机放地面，等待 GPS 锁定（Jetson 日志出现"飞控准备就绪"）
4. 等待 Jetson 日志出现"self check all ready"播放第一段音乐
5. 操作手将遥控器切到 AUTO 并解锁油门（抛飞）
6. 全程无需任何操作，等待降落
```
