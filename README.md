# CUADC 2025 项目资料

我们需要制作一架固定翼无人机，可以自主起飞，在任务区域内识别数字或图像天井，然后决策向其中一个天井投放物资载荷(一瓶矿泉水)，并自主着落。在无人机起飞后的全流程中不允许对无人机进行任何操作行为。
