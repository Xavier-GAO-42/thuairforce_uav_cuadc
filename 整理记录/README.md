# 资料来源与整理记录

这里集中保存发布准备、历史版本及核对记录，不属于技术正文的阅读主线。

## 1. 发布状态

[发布准备说明](发布说明.md)记录材料范围、许可状态、已知缺口和本次整理边界。

## 2. 版本与来源

- [历史程序版本差异](历史程序版本差异/README.md)：独立历史仓库中的不同代码与忽略配置，完整文件保留。
- `历史仓库版本.csv`：来源仓库的本地 HEAD。
- `反思合并来源.csv`：两版复盘原文的来源和 SHA256。
- `桌面补充材料来源.csv`：本次补充的参数、航点、模型、制造文件和配图的来源及 SHA256。

## 3. 完整性核对

- `敏感信息检查.json`：公开目录的敏感信息检查范围与清理类别，不记录被删除的敏感值。
- `原始材料覆盖核对.csv`：每项原始材料在当前资料包的对应位置。
- `文档正文保留核对.csv`：技术正文与原文的核对记录。
- `文件清单与校验.csv`：当前文件的位置、来源、处理方式与 SHA256，不包含清单自身。
